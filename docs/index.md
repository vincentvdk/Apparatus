# Apparatus OS

A Fedora-based immutable desktop operating system powered by Hyprland, designed for developers and power users.

## What is Apparatus OS?

Apparatus OS is a custom immutable Linux distribution that combines:

- **Fedora** base with OSTree for atomic updates
- **Hyprland** as the Wayland compositor for a tiling window management experience
- **Distrobox** for seamless container-based development environments
- **Pre-configured tools** for a productive development workflow

## Key Features

| Feature | Description |
|---------|-------------|
| Immutable OS | Atomic updates via bootc, rollback capability |
| Hyprland WM | Dynamic tiling with extensive customization |
| Distrobox Integration | Easy container management with host integration |
| Butler CLI | Unified configuration management tool |
| Pre-configured | Zsh, Neovim, Kitty, and more ready to use |
| Themed | Catppuccin themes for consistent aesthetics |

## Quick Start

1. **Install**: Download the latest ISO from releases and install to your system
2. **Login**: Use the default credentials or your configured user
3. **Explore**: Open a terminal with Super+Return and start using butler
